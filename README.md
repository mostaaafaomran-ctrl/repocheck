# RepoCheck

**Paste a public GitHub repo and get a health score out of 100 with a fix list. Free, no signup.**

**[Open live](https://mostaaafaomran-ctrl.github.io/repocheck/)**

## English
RepoCheck looks at a public repo through the GitHub API and scores 12 things that make people trust and use a project:
README, license, description, topics, demo link, tests, CI, issue templates, CONTRIBUTING, .gitignore, recent activity, and a release.
You get a ring score, a fix list sorted by points, and a ready badge for your README.
- Runs in your browser. No token, no backend. (GitHub allows 60 anonymous requests per hour per IP.)
- English and Arabic UI.
- Deep link: `?repo=owner/name`.

The checks are simple file-name and metadata rules, not code quality analysis.

## بالعربي
الصق رابط ريبو عام وهتطلع بنتيجة من 100 وقائمة إصلاحات مرتبة بالنقاط: README، ترخيص، وصف، topics، لينك ديمو، اختبارات، CI، قوالب issues، دليل المساهمة، .gitignore، نشاط حديث، وrelease. بيشتغل في متصفحك من غير توكن.
